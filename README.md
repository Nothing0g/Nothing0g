## `about_me.log`

My work sits at the intersection of **AI engineering, data analytics, and engineering workflows**. I value interpretable baselines, traceable evidence, reproducible tests, and clear limitations—not just a model that runs.

> **Start with the decision. Show the evidence. Keep a human in the loop.**

My engineering internships provide domain context in turbine maintenance, cryogenic systems, and plant design. The AI projects below are independent portfolio prototypes; they were not commissioned or deployed by those organizations.

### `working_principles[]`

1. Start with the user or operational decision, not the model.
2. Make assumptions, data gaps, and synthetic-demo boundaries visible.
3. Prefer interpretable baselines before unnecessary complexity.
4. Test edge cases and keep regression failures reproducible.
5. Return evidence, uncertainty, and human-review paths when confidence is limited.
