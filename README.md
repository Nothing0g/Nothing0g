## What I try to demonstrate in every project

1. Start with the user or business decision, not the model.
2. Make assumptions and data limitations visible.
3. Prefer interpretable baselines before unnecessary complexity.
4. Add tests, evaluation, failure analysis, and reproducible commands.
5. Design systems that can abstain or request human review when evidence is weak.
